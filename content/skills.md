## Backend

Anjo's primary backend stack is C# with ASP.NET Core, including REST API design and Entity Framework Core for data access. He also builds backend services with Node.js and NestJS in TypeScript. His public .NET work includes a .NET 9 Clean Architecture Web API starter kit (NovaStarterKit) and several C# console applications built around Clean Architecture and SOLID principles.

## Frontend

On the frontend Anjo works with Angular, React, and Next.js, all in TypeScript. He has published Angular starter/dashboard repositories and React Native starter projects, and this portfolio is built with Next.js and React.

## Data

Anjo works with PostgreSQL and SQL Server as relational databases, MongoDB as a document store, and Redis for caching. This portfolio's semantic search index uses PostgreSQL with the pgvector extension.

## Cloud

Anjo has experience with AWS and Azure as cloud platforms and designs systems with cloud deployment, scalability, and managed services in mind. The portfolio does not list specific individual AWS or Azure services.

## DevOps

Anjo uses Docker for containerised development and deployment, GitHub Actions and Azure DevOps for CI/CD pipelines, and maintains Docker-first starter templates for several stacks.

## Architecture

Anjo applies Clean Architecture, Vertical Slice Architecture, Domain-Driven Design (DDD), CQRS, and event-driven systems where the problem warrants them, preferring the simplest architecture that fits the problem.

## AI Engineering

Anjo's AI engineering skills cover LLM integration, retrieval-augmented generation (RAG), agentic coding, AI-assisted development, developer automation, and building Claude Code plugins and agent workflows. Asterweave, his agentic software delivery framework, and this RAG-grounded portfolio assistant are his main public examples.
