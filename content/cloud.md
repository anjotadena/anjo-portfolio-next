## Cloud platforms

Anjo works with AWS and Azure as cloud platforms. He designs systems with cloud deployment, scalability, and managed services in mind rather than assuming a single fixed server. The portfolio does not currently list the specific individual AWS or Azure services he has used; ask him directly for details about a particular service.

## Cloud-native design

Anjo's cloud-native approach favours managed services over self-hosted infrastructure where they fit, containerisation with Docker so workloads run consistently across environments, and designing for horizontal scale and observability from the start. Configuration and secrets are kept out of source control and supplied through the environment.

## Deployment targets

For web applications Anjo deploys to Vercel — this portfolio and the Asterweave documentation site are both hosted there — while keeping alternative deployment possible through Docker images. Databases such as PostgreSQL are run as managed services or in containers depending on the environment.
