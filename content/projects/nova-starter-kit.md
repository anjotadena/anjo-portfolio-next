## Overview

NovaStarterKit is a Clean Architecture .NET 9 Web API starter kit with CQRS, SOLID principles, and modular design. It captures the project structure Anjo reaches for when starting a new ASP.NET Core service, so that new backends begin with clear boundaries between domain, application, infrastructure, and API layers.

## Architecture

The kit follows Clean Architecture with dependencies pointing inward toward the domain, uses CQRS to separate commands from queries, and is organised into modules so features can be added without cross-cutting changes.

## Technologies

C#, .NET 9, ASP.NET Core.

## My Role

Anjo is the creator of NovaStarterKit. It is one of several public C# projects — alongside AlgoJourney and DailyCodeGrind — in which he applies Clean Architecture and SOLID principles.
