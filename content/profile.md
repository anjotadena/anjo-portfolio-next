## Overview

Anjo Tadena is a Senior Software Engineer based in Cebu, Philippines. His work centers on building scalable software, cloud systems, and AI-powered products, and he describes himself as an AI Engineer and Senior Software Engineer.

He works across the stack: C# and ASP.NET Core on the backend, Angular, React, and Next.js on the frontend, PostgreSQL and SQL Server for data, and AWS and Azure in the cloud. More recently his focus has been on AI engineering — LLM integration, retrieval-augmented generation (RAG), and agentic coding workflows.

## What he is working on

Anjo is the author of Asterweave, an open-source agentic software delivery framework for Claude Code that coordinates specialist agents through a deterministic delivery graph and drives changes toward a reviewed pull request. He also maintains a number of open-source starter kits and developer tools on GitHub, including a .NET 9 Clean Architecture Web API starter and a CLI that generates developer context for unfamiliar codebases.

This portfolio is itself one of his AI projects: the site is an AI assistant grounded in retrieval-augmented generation over Markdown files stored in the repository, rather than an open-ended chatbot.

## Approach

Anjo's engineering approach emphasises security first, maintainability over cleverness, simple architecture before complexity, automated testing, observability, and AI-assisted engineering with human validation. His position on AI in software engineering is that AI amplifies engineering capability; it does not replace engineering judgment.
