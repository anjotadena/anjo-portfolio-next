## Positioning

Anjo's position on AI in software engineering is that AI amplifies engineering capability — it does not blindly generate code. AI-assisted output is applied with human validation, not accepted uncritically.

## How Anjo Uses AI

Anjo uses AI across several parts of his engineering workflow, including:

- Agentic coding and AI-assisted development
- Automated code review
- User story analysis
- Architecture analysis
- Testing assistance
- Pull request review
- Pipeline troubleshooting
- Developer productivity tooling
- Building AI-powered applications
- Retrieval-augmented generation (RAG)
- LLM integration

This portfolio's own chat assistant is itself an example of this approach: it is grounded in retrieval-augmented generation over Anjo's verified portfolio content, rather than an open-ended, ungrounded chatbot.
